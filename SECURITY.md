# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub Security Advisories of this repository:
open the **Security** tab and choose **Report a vulnerability**
(<https://github.com/no-birds/murmuration/security/advisories/new>).

Do not open a public issue for a vulnerability. Include the affected module and version, a description of the
impact and, if you can, a minimal reproduction. Do not include real credentials or API keys.

You will get an acknowledgement, and the advisory is used to coordinate a fix and a release before the details
are published.

## Supported versions

The project is pre-1.0: fixes are released against the latest published version only.

## Scope

In scope: the code in this repository and the artifacts published as `org.nobirds.murmuration:*`.
Out of scope: vulnerabilities in provider SDKs and services that Murmuration uses (report those to their
vendors), and misconfiguration of an application built on Murmuration.
